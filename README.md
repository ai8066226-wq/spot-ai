# محرك البحث عن استراتيجيات Bybit

## التثبيت والتشغيل
```bash
pip install -r requirements.txt
python main.py --demo --fast                                  # تجربة سريعة بدون إنترنت
python main.py --symbol BTCUSDT --interval 60 --days 1095     # بيانات حقيقية، ساعة، 3 سنوات
python main.py --symbol ETHUSDT --interval 240 --days 1460 --mode rules
python main.py --symbol SOLUSDT --interval 15 --days 365 --mode ml
```
النتائج تُحفظ في `results/`: جداول CSV، ورسم منحنى رأس المال، وأهمية الميزات.

## الملفات
| الملف | الوظيفة |
|---|---|
| `data_bybit.py` | جلب الشموع من Bybit API v5 (بدون مفاتيح) مع تخزين محلي |
| `indicators.py` | RSI, MACD, EMA, Bollinger, Keltner, ATR, ADX/DI, SuperTrend, Stoch RSI, MFI, OBV, VWAP, Donchian, CCI, Ichimoku + ميزات مطبّعة للتعلم الآلي |
| `backtest.py` | محرك اختبار: TP/SL بمضاعفات ATR أو %، وقف متحرك، خروج زمني، افتراض عمولة فورية 0.1% لكل جهة + انزلاق |
| `strategies.py` | 10 استراتيجيات مع شبكة معاملات — أضف استراتيجيتك بسهولة |
| `search.py` | بحث شبكي متوازٍ مع walk-forward وفلتر صلابة وبيانات مخفية OOS |
| `ml_engine.py` | وسم Triple-Barrier + LightGBM + walk-forward مع purge |

## المنهجية (لماذا النتائج قابلة للثقة)
1. **آخر 30% من البيانات مخفية** ولا تُستخدم إلا مرة واحدة في النهاية.
2. **كل تركيبة تُقاس على 4 نوافذ زمنية**؛ تُقبل فقط إن ربحت في ≥75% منها وPF أسوأ نافذة ≥0.9.
3. **الدخول عند افتتاح الشمعة التالية** ولمس الهدف والوقف بنفس الشمعة يُحسب وقفاً (افتراض متحفظ).
4. **التعلم الآلي**: العتبة تُختار على جزء معايرة داخل التدريب فقط، وفجوة purge بطول الأفق تمنع تسرب الوسوم.
5. عمود `passed` في `top_strategies_oos.csv` هو المعيار: PF خارج العينة > 1.1 و ≥10 صفقات.

## تحذيرات مهمة
- كلما اختبرت تركيبات أكثر زاد احتمال إيجاد "رابح" بالصدفة. الرقم الوحيد المهم هو OOS.
- اختبر الاستراتيجية الناجحة على عملات وأطر زمنية أخرى؛ الحافة الحقيقية تظهر في أكثر من سوق.
- الأداء الحي عادةً أضعف من الاختبار: جرّب على Bybit Testnet أو بمبلغ صغير شهراً على الأقل قبل أي رأس مال حقيقي.
- هذه النسخة للتداول الفوري والشراء فقط، دون تمويل أو رافعة أو بيع على المكشوف.


## استبدال المشروع السابق

هذا هو المشروع البديل المرفق من المستخدم، مع تقييد البيانات والاستراتيجيات والتعلم الآلي بالتداول الفوري والشراء فقط. ملفات المشروع القديم حُذفت من الفرع الحالي ويمكن استرجاعها من سجل Git. لا KDJ ولا أوامر تداول حقيقية. حد العمال المتوازيين الافتراضي4.

عمولة0.1% وانزلاق0.02% لكل جهة افتراضات بحثية وليست تسعيرًا مؤكدًا لحساب Bybit. منهجية القبول والتقسيم هنا هي الموجودة في المشروع المرفق (30% OOS)، وليست منهجية المحرك السابق. لا تعتبر الفترات التي فُحصت سابقًا بيانات جديدة مستقلة. يستعمل المحرك الحالي كامل رأس المال نظريًا دون ضبط حجم مخاطر مماثل للقديم.

الاختبارات الآلية تستخدم بيانات اصطناعية للتحقق البرمجي فقط ولا تثبت الربحية. التعلم الآلي يُدرّب أثناء تشغيل --mode ml أوall، ولا يتعلم باستمرار بعد انتهاء المهمة ولا يحفظ نموذجًا جاهزًا للتداول تلقائيًا. تقييم عدة مرشحين على OOS لا يجعله ضمانًا ضد فرط الملاءمة.
