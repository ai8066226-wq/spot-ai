# خادم Bybit Spot AI

هذا هو الجزء الذي يشغّل مكتبات Python والتدريب والتداول. تطبيق Kotlin عميل اتصال وتحكم؛ لا يشغّل LightGBM داخل الهاتف. ملفات engine من مشروع bybit_engine المرفق، مع طبقة خادم جديدة للتدريب ذي إعداد ثابت وإدارة الجلسة. لا KDJ.

## تشغيل الخادم

يلزم خادم خاص متاح لـBybit، Docker وDocker Compose، واسم نطاق مع HTTPS صالح. GitHub Actions ليس خادم تداول دائمًا. لا ترفع .env أو state أو المفاتيح إلى GitHub. لا تُدخل مفاتيح حساب حقيقية أثناء اختبار التطوير.

1. انسخ مجلد backend كاملًا إلى الخادم وافتحه.
2. انسخ .env.example إلى .env.
3. ولّد ENGINE_TOKEN عشوائيًا (مثل `python -c "import secrets; print(secrets.token_urlsafe(40))"`). ولّد ENGINE_ENCRYPTION_KEY بـ`python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"` بعد تثبيت cryptography. ضع الناتجين في .env، دون علامات اقتباس إضافية، واحمِ الملف بصلاحية600.
4. اترك ENABLE_REAL_TRADING=false. شغّل `docker compose up -d --build`.
5. ضع reverse proxy مثل Caddy أمام `127.0.0.1:8080` مع شهادة TLS. نموذج Caddyfile بعد استبدال اسم النطاق:
```
engine.example.com {
    reverse_proxy 127.0.0.1:8080
}
```
6. لا تعرض منفذ8080 للإنترنت. لا تعطل التحقق من الشهادة. ضع رابط النطاق `https://engine.example.com` ورمز ENGINE_TOKEN في التطبيق، واضغط حفظ الاتصال.

الخادم مخصص لمستخدم واحد. لا تشارك رمز الاتصال. احفظ مفتاح التشفير والقرص الدائم بأمان؛ فقدانه يمنع استرجاع المفاتيح. يعمل الخادم بعامل واحد فقط؛ تشغيل عدة نسخ على قاعدة البيانات نفسها غير مدعوم. ملفات النماذج pickle محلية، ولا يقبل الخادم رفع نموذج من مصدر غير موثوق.

## الاستخدام

1. في صفحة الإعدادات احفظ رابط HTTPS ورمز الخادم. يحفظهما الهاتف بتشفير AndroidKeyStore.
2. اختر الوضع: ورقي paper، أو حساب Bybit Demo، أو حقيقي real. الورقي لا يرسل أوامر إلى المنصة. Demo والحقيقي لهما مفاتيح منفصلة. احفظ مفتاحًا بصلاحية التداول الفوري دون سحب، ويفضل تقييد IP الخادم.
3. اختر من عملة إلى10 عملات متاحة فعليًا في Bybit Spot مقابل USDT. لا توجد عقود أو رافعة أو بيع على المكشوف.
4. حدد الميزانية الإجمالية بـUSDT. تقسم بالتساوي بين العملات، ولكل عملة مركز واحد. يُترك هامش صغير للرسوم. استخدم رصيدًا مخصصًا؛ العمليات اليدوية خارج التطبيق ليست ضمن سجل الجلسة.
5. اختر زمن الشموع والتاريخ من/إلى بتوقيت UTC. يجلب الخادم الشموع المغلقة فقط، ويرفض الفجوات. الحد100000 شمعة لكل عملة، وحد أدنى2000 للتدريب. توفر التاريخ يتوقف على تاريخ الإدراج.
6. اضغط جلب التاريخ وبدء التدريب، ثم راجع صفحة النتائج. لا يبدأ التداول تلقائيًا بعد التدريب.
7. اضغط تشغيل المحرك بعد اجتياز العملات المختارة. الحقيقي يحتاج ENABLE_REAL_TRADING=true على الخادم وتأكيدًا منفصلًا في التطبيق.

## التدريب والقبول

لكل عملة نموذج LightGBM، أو بديل sklearn عند غياب المكتبة. الخطة ثابتة: هدف1.5ATR، وقف1ATR، وأفق24شمعة. أول70% للتدريب والمعايرة، وآخر30% للاختبار، مع فجوة purge لمنع تداخل الوسوم. اختيار العتبة في المعايرة فقط. لا يعيد هذا المسار بحث كل إعدادات المختبر السابق، ولا يعيد التدريب تلقائيًا كل يوم.

شروط اجتياز البحث:20 صفقة اختبار على الأقل، PF>=1.5، عائد موجب، تراجع رأس المال عند إغلاق الصفقات<=10%، وعائد موجب عند مضاعفة التكاليف. تُرفض العملة عند غياب عتبة مربحة أو فشل الجلب أو تحقق البيانات. تغيير العملات أو الفاصل أو التاريخ يتطلب تدريبًا مطابقًا جديدًا.

نسبة النجاح المعروضة هي نسبة الصفقات الرابحة تاريخيًا، وليست ضمانًا للتنبؤ أو الربح. بيانات سبق فحصها في تجارب أخرى لا تصبح اختبارًا مستقلًا. اختبار النموذج يفترض كامل رأس المال لكل صفقة؛ الجلسة الفعلية تستخدم الميزانية المقسمة. لا تقارن نسبهما دون هذا الفرق.

## التنفيذ والأوامر

يفحص الخادم السوق كل15ثانية. الدخول بعد إغلاق الشمعة في أول فحص متاح، وليس بالضرورة سعر افتتاح الشمعة التاريخي. الخروج عند السعر المراقب للهدف أو الوقف، أو مرور24شمعة. لا يوجد وقف متحرك في المراقب الحي بهذا الإصدار؛ الخطة المربوطة بالنموذج هي ATR الثابتة.

**الوقف والهدف مراقبان على الخادم، وليسا أمرين حاميين مقيمين على المنصة.** تعطل الخادم أو الشبكة قد يؤخر الخروج؛ يمكن أن تتجاوز الخسارة الحدود. يمنع فتح شراء جديد عند هبوط تقييم الجلسة10%، لكنه لا يضمن حدًا للخسارة.

أوامر المنصة Market، دون اقتراض، مع حد انزلاق0.50%، وقد تنفذ جزئيًا أو تُلغى. تُراجع حدود الحجم والدقة من المنصة. قبول الطلب لا يُسجل ربحًا أو تعبئة؛ يتحقق الخادم من حالة الأمر وتفاصيل التنفيذ. الطلب مجهول النتيجة يوقف الحلقة ولا يُعاد إرساله. استخدم زر مصالحة الطلب بعد التحقق. العمولات تدعم عملة الأساس أو USDT؛ عملة عمولة ثالثة تستلزم مراجعة يدوية.

**الإيقاف:** يوقف الحلقة، لكنه لا يلغي أمرًا أُرسل بالفعل ولا يبيع المراكز المفتوحة. تبقى الأصول مملوكة لك وتظهر في النتائج؛ يجب إدارتها يدويًا أو إعادة تشغيل المحرك. تغيير إعدادات الجلسة مع مراكز مفتوحة محظور. إعادة تشغيل الخادم تسترجع السجل وتترك التداول متوقفًا احترازيًا؛ لا تستأنف أموالًا حقيقية بصمت.

لم تُجرَ أوامر بأموال حقيقية أو حساب Demo خلال التحقق من هذه الحزمة. يبدأ الحقيقي معطلًا، ولا تتضمن الحزمة مفاتيح أو خادمًا منشورًا مسبقًا.

## العمل في الخلفية

المحرك يعمل على الخادم بعد إغلاق التطبيق، ما دام الخادم والشبكة يعملان. خدمة الهاتف إشعار ومتابعة فقط. Android15+ قد يحد خدمة dataSync إلى6ساعات خلال24ساعة. انتهاء إشعار الهاتف لا يوقف الخادم؛ وإطفاء الهاتف أو إيقاف التطبيق قسريًا لا يوقفه أيضًا. لا يوجد وعد بتشغيل أبدي أو تجاوز قيود Android.
